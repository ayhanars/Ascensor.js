Figma access token

This lets the plugin read the Component Status page from the CO/CO Design Library file, so it can show whether a component is implemented, has an update available, or hasn't been started yet for COBA/Purple. It only needs to be set up once — ask your plugin admin for the token if you don't have one yet, or generate your own:

  1. Open Figma (web or desktop app) and click your profile picture in the top-left corner.
  2. Click Settings.
  3. Open the Security tab.
  4. Scroll down to Personal access tokens and click Generate new token.
  5. Give it a name, e.g. Screen Component Inspector.
  6. Under scopes, find File content and set it to Read-only. Leave every other scope off.
  7. Click Generate token.
  8. Copy the token right away — Figma only shows it to you once.
  9. Paste it into the field below and click Save.
